# Edit, save, and check the diff

Change a heading, tick a task, or edit a table cell, then save as usual.

markami applies each change to your Markdown as a small, local edit. In a Git repository, the Source Control view shows only the lines you changed.

The sample document is an untitled file and is not in a Git repository, so it cannot show a diff. To see one, open a Markdown file from your own Git repository in markami and edit it there.
